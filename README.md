| Method | Path | Contract |

Conversation fields are id/title/createdAt/updatedAt. Message fields are id/conversationId/role/content/status/createdAt, plus optional progress/toolCalls arrays. IDs are nonempty strings; message conversation ownership, enum statuses and timestamp offsets are validated. Duplicate IDs fail closed. Safe Markdown supports paragraphs, headings, bullets, numbered steps, inline code and fenced code blocks through React text nodes; raw HTML is never injected and links are not activated. Only explicitly selected public fields cross the adapter; reasoning, chainOfThought, hiddenReasoning, internalPrompt and other unknown fields are discarded. Capabilities include chat, streaming, stop, commands, toolCalls, progressTrace, retryMessage, retryCall and sourceTargeting, all false by default. Streaming is opt-in only when streaming=true AND streamProtocol=athena-snapshot-v1 are advertised. Otherwise the adapter uses full JSON responses and makes no streaming claim. This integration contract uses the same messages POST with Accept: text/event-stream. Each SSE data event contains {sequence, requestId, messages}; sequence is a nonnegative monotonic integer and messages are absolute persisted snapshots, not text deltas. Duplicate/older sequence events are ignored, stable message IDs replace prior snapshots rather than concatenating text, and a changed requestId is rejected. The final assistant must have done/failed/cancelled status before EOF. Incomplete streams fail explicitly. Other streaming protocols require an adapter before enabling them. No stream reconnect, background polling or server implementation is assumed.

All requests are abortable and time-limited (30 seconds JSON; 120 seconds streaming). StrictMode's discarded initial mount does not fetch. The hook prevents duplicate active sends and ignores aborted/stale callbacks. Conversation creation is deferred until first send and never repeated on page load.
